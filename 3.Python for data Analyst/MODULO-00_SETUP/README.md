# MODULO 00 — Setup del entorno

**Objetivo:** Dejar a todo el mundo con Python, Jupyter y el entorno del curso funcionando antes de la clase 1.

**Prerequisito:** Ninguno.

**Entregable:** `Reto_00_Verifica_tu_entorno.ipynb` corriendo entero sin error, exportado a PDF o captura del output final.

---

## Temario

1. Instalar Anaconda / Miniconda
2. Crear el entorno `pyda3` desde `_RECURSOS/environment.yml`
3. Abrir JupyterLab y ejecutar la primera celda
4. Celdas, modo comando vs edicion, atajos de Jupyter
5. Estructura de carpetas del curso y rutas relativas
