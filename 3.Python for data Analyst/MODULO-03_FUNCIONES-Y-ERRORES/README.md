# MODULO 03 — Funciones y manejo de errores

**Objetivo:** Empaquetar logica en funciones reutilizables y que el programa no muera ante un dato malo.

**Prerequisito:** MODULO-02 completo.

**Entregable:** `Reto_03_Funciones_y_Errores.ipynb` resuelto.

---

## Temario

1. `def`, parametros, argumentos por defecto, `return`
2. Scope: variables locales vs globales
3. Funciones que llaman funciones
4. `lambda` y su uso con `map` / `filter`
5. Excepciones: `try` / `except` / `else` / `finally`
6. Errores tipicos: ValueError, KeyError, TypeError, ZeroDivisionError
7. Docstrings y `assert` como chequeo minimo
