# MODULO 07 — Git y GitHub para analistas

**Objetivo:** Versionar el trabajo, no perder nada nunca y publicar un portafolio en GitHub.

**Prerequisito:** MODULO-06 completo. Git instalado y cuenta de GitHub creada.

**Entregable:** Repo publico en GitHub con el proyecto del MODULO-05 versionado, README y al menos 5 commits con mensajes utiles.

---

## Temario

1. Por que un analista necesita git (el problema de `analisis_final_v3_ok.ipynb`)
2. Instalacion y configuracion inicial: `user.name`, `user.email`
3. El ciclo diario: `status` -> `add` -> `commit` -> `push`
4. `.gitignore` y por que los datos y credenciales no se suben
5. Ramas: `branch`, `switch`, `merge` y como resolver un conflicto
6. GitHub: repo remoto, `clone`, `pull`, Pull Request
7. README de un proyecto de datos que se entiende sin explicacion
8. Notebooks en git: limpiar outputs antes de commitear
