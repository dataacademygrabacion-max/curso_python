# MODULO 02 — Control de flujo

**Objetivo:** Escribir logica que decide y que repite: listas, diccionarios, if y bucles.

**Prerequisito:** MODULO-01 completo.

**Entregable:** `Reto_02_Control_de_Flujo.ipynb` resuelto.

---

## Temario

1. Listas y tuplas: crear, indexar, cortar, metodos
2. Diccionarios: claves, valores, `.get()`, recorrido
3. Booleanos y operadores logicos
4. `if` / `elif` / `else`
5. `for`, `while`, `range()`, `break` y `continue`
6. List comprehensions (introduccion)
