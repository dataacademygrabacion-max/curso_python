# MODULO 08 — Visualizacion de datos

**Objetivo:** Convertir un DataFrame en un grafico que responde una pregunta de negocio.

**Prerequisito:** MODULO-05 completo.

**Entregable:** `Reto_08_Visualizacion.ipynb` resuelto: 4 graficos + una conclusion escrita por grafico.

---

## Temario

1. Anatomia de matplotlib: `figure`, `axes`, `plot`
2. Graficos base: linea, barras, barras horizontales, histograma, dispersion, pastel (y cuando NO usarlo)
3. El atajo `df.plot()` de pandas
4. Seaborn: `barplot`, `boxplot`, `heatmap`, `pairplot`
5. Titulos, ejes, leyendas, formato de numeros y anotaciones
6. Subplots y figuras compuestas
7. Elegir el grafico segun la pregunta
8. Guardar en PNG con `savefig(dpi=150, bbox_inches='tight')`
